# Ecommerce Core

Ядро интернет-магазина для учебного курсового проекта. Реализовано на Python с использованием ООП-подхода.

## Описание проекта
Проект представляет собой базовую архитектуру e-commerce системы.

### Домашнее задание 14.1: Введение в ООП
Реализованы ключевые сущности:
- **Product**: Товар с названием, описанием, ценой и остатком на складе.
- **Category**: Категория товаров с автоматическим подсчетом общего количества категорий и товаров в системе через атрибуты класса.

### Домашнее задание 14.2: Режимы доступа
Добавлена инкапсуляция и защита данных:
- **Приватные атрибуты**: `__products` в Category, `__price` в Product
- **Геттеры**: `@property products` (возвращает строку), `@property price`
- **Сеттер**: `@price.setter` с валидацией (> 0)
- **Класс-метод**: `Product.new_product()` — создание из словаря
- **Метод добавления**: `Category.add_product()` с инкрементом счётчика
- **Покрытие тестами**: 100% (9 тестов)

## Домашняя работа 15.1 — Магические методы

### Реализовано:
- `Product.__str__()` — строковое представление продукта
- `Category.__str__()` — строковое представление категории с подсчётом общего количества товаров
- `Product.__add__()` — сложение продуктов (цена × количество)
- Тесты для новой функциональности (покрытие 100%)

В дальнейшем ядро будет расширено функционалом корзины, оформления заказов и интеграцией с внешними интерфейсами (Web, Telegram Bot).

## Установка и запуск
1. Клонируйте репозиторий:
   
   git clone https://github.com/MaksimusMag/ecommerce-core.git
   cd ecommerce-core
2. Установите зависимости:
   poetry install
3. Запустите демонстрационный скрипт:
   poetry run python main.py

# Проверка форматирования
poetry run black --check src/ tests/

# Автоформатирование
poetry run black src/ tests/

# Проверка сортировки импортов
poetry run isort --check-only src/ tests/

# Сортировка импортов
poetry run isort src/ tests/

# Проверка стиля (PEP8)
poetry run flake8 src/ tests/ --max-line-length=120

# Запуск тестов с отчетом о покрытии
poetry run pytest tests/ --cov=src.hw_14_1_oop.product --cov-report=html
